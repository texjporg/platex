\section{\LaTeXe\ \texttt{<2021-11-15>}対応}
→参考：|texjporg/platex#97|

内部処理で\LaTeXe{}の修正に追随する調整を行いました。


\section{フロート内で組方向を無理やり変更した場合のエラーメッセージの改良}
→参考：|texjporg/platex#95|

フロート環境で組方向を|\yoko|又は|\tate|で直接変えようとすると、
\begin{Verbatim}[fontsize=\small]
! Output loop---100 consecutive dead cycles.
\end{Verbatim}
のような分かりにくいエラーが発生していました。

\pLaTeXe\ \texttt{<2023-02-14>}では、
より明快なエラーメッセージが出力されるよう改良しました。
\begin{Verbatim}[fontsize=\small]
! LaTeX Error: Direction change inside float!?
\end{Verbatim}


\section{\LaTeXe\ \texttt{<2023-06-01>}対応}
→参考：|texjporg/platex#100|

\LaTeXe{}の起動時のバナー出力処理の変更に追随する対応を行いました。
これに伴い、\pLaTeXe{}起動時のバナーの形式が変更されています。

\LaTeXe\ \texttt{<2022-11-01>}以前：
\begin{Verbatim}[fontsize=\small,breaklines]
pLaTeX2e <2023-02-14>+1 (based on LaTeX2e <2022-11-01> patch level 1)
\end{Verbatim}

\LaTeXe\ \texttt{<2023-06-01>}以降：
\begin{Verbatim}[fontsize=\small,breaklines]
pLaTeX2e <2025-11-01>, based on
LaTeX2e <2025-11-01> patch level 1
\end{Verbatim}


\section{\LaTeXe\ \texttt{<2025-06-01>}対応}
→参考：|texjporg/platex#102|

新しい\LaTeXe\ \texttt{<2025-06-01>}では
出力ルーチンに大きな変更が加えられました。
\pLaTeXe{}では日本語拡張部分に影響する箇所を中心に対応を行い、
従来\LaTeXe{}本体に直接パッチしていた部分を
可能な限りフックやソケット／プラグ機構を用いる形に書き換えました。

\subsection{ボトムフロートと脚注}

従来の\pLaTeXe{}では、ボトムフロート→脚注の順で
出力されるよう出力ルーチンを再定義していました。
\LaTeXe\ \texttt{<2025-06-01>}で新たに追加された
\texttt{build/column/outputbox}ソケット／プラグ機構により、
ボトムフロートと脚注の出力順序を構成可能になりました。

\LaTeXe{}標準では、次のプラグが用意されています：
\begin{itemize}
  \item \texttt{floats-space-footnotes}
  \item \texttt{space-floats-footnotes}
  \item \texttt{floats-footnotes}
\end{itemize}

しかし、いずれも従来の\pLaTeXe{}の挙動とは異なるため、
過去の\pLaTeXe{}の動作を再現する
\texttt{floats-footnotes-platex}プラグを新たに定義し、
それを\texttt{build/column/outputbox}ソケットに設定しました。

\subsection{トンボ}

トンボ出力処理をフックを用いる形に書き換えました。

トンボ出力はカーネルに入れるべき機能とは言い切れず、
将来的には外部パッケージへの移譲も検討されています。
GitHubのIssue等でのご意見を歓迎します。

\section{開発版のテストのお願い}
特に2020年以降、オリジナルの\LaTeX{}が活発に開発されており、
その変更点が\pLaTeX{}に波及するケースが増えてきました。
そのようなケースの見落としを避け、かつ、今後\pLaTeX{}に
導入するかもしれない修正や仕様変更を事前にテストしていただく
ことは、予期しないバグの防止につながります。
ぜひ開発版のテストにご協力ください。いくつかの方法があります。

最も簡単な方法は「通常のコマンド名 |platex| の代わりに
|platex-dev| というコマンドを起動する」というものです。
通常のコマンドは
「\LaTeXe{}の\emph{安定版}に\pLaTeXe{}を載せたもの」
ですが、|-dev| 付きコマンドは
「\LaTeXe{}の\emph{開発版}に\pLaTeXe{}を載せたもの」
になります。
コマンドラインで直接実行するほか、以下の方法でも利用可能です。
\begin{itemize}
 \item ローカルインストール不要で、すぐにWeb上で\pLaTeX{}を
  実行できるサービス
  Cloud LaTeX (https://cloudlatex.io/ja)
  には、2021/05/09以降、
  プロジェクト設定に「開発版を試す」という機能が用意されています。
  これは |platex| の代わりに |platex-dev| を起動するものです。
  これで、一般のユーザの方々にも開発版のテストに参加していただき
  やすくなりました。
 \item \TeX Shopや\TeX worksなどの支援環境を使用する場合、
  起動コマンド名に |ptex2pdf -l ...| とある箇所を
  |ptex2pdf -ld ...| に変更すれば、開発版が起動します。
\end{itemize}
この方法によって、\pLaTeXe{}が開発版\LaTeXe{}に非対応の箇所を
あぶり出すことができます。

さらに、\pLaTeXe{}特有の試験的コードを配布する場合もあります。
\TeX{}ファイルの冒頭（|\documentclass|より前）で
\begin{verbatim}
  \RequirePackage{exppl2e}
\end{verbatim}
と書くことで、\pLaTeXe{}の開発版コードも上乗せできます。
詳細は\file{exppl2e.pdf}を参照してください。ここには、
その他の\pLaTeXe{}の既知の制約事項も記載しています。

開発版をお試しいただき、\TeX\ ForumやGitHubのIssueでの
バグ報告やご意見を歓迎します。
\begin{itemize}
\item \texttt{https://github.com/texjporg/platex}
\item \texttt{https://github.com/texjporg/uplatex}
\end{itemize}
